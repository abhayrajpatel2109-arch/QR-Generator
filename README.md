# 📲 QR Code Generator

A lightweight, responsive, and easy-to-use QR Code Generator web application built using HTML5, CSS3, and JavaScript.
------------------------------
## ✨ Features

* **⚡ Instant Generation:** Generates high-quality QR codes in real-time as you type or submit.
* **🔗 Multi-Purpose Support:** Works with URLs, plain text, contact details, and Wi-Fi credentials.
* **📥 Easy Download:** Download the generated QR code directly as an image file.
* **📱 Fully Responsive:** Clean UI optimized for mobile, tablet, and desktop screens.
-------------------------------
## 🛠️️ Tech Stack

* **HTML5:** Semantic layout and structure.
* **CSS3:** Custom styles, Flexbox/Grid, and responsive design.
* **JavaScript (ES6):** Core logic and dynamic DOM manipulation.
* **API / Library:** Uses QRCode.js / QR Code API for rendering images.
